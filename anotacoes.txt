O aplicativo estava apontando para uma URL da pythonanywhere.
Para fazer funcionar, rodei o pycodebr_flix_api e configurei a URL base desse projeto


Em api\service.py:
def __init__(self):
    # self.__base_url = 'https://pycodebr.pythonanywhere.com/api/v1/'
    self.__base_url = 'http://127.0.0.1:8000/api/v1/'
    self.__auth_url = f'{self.__base_url}authentication/token/'
